Version, verification & troubleshooting ＋

If Android asks, allow your file manager to install this app. NEXUS is currently a downloaded test APK, not a Play Store release. If installation fails, check that your device runs Android 7.0 or newer.

For streaming apps, install and sign in to the appropriate official app. NEXUS does not include paid subscriptions. For movie discovery, add your own TMDb read token in Settings; this download does not include the developer’s personal credentials.

Phones open in landscape. Touch/remote interface selection is planned. TV and Bluetooth remote compatibility still needs physical testing.
